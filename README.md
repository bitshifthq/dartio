# DartIO

Portable I/O and systems packages for Dart, across native and web runtimes.

DartIO is where we build focused Dart packages for the parts of I/O that need
more than the SDK alone can provide. That includes process, terminal,
transport, filesystem, device, networking, and other systems work across
native and web runtimes.

This is not a replacement for `dart:io`. Think of it as a home for the
lower-level packages that help Dart reach more platforms while still feeling
like Dart.

## Packages

| Package                 | Description                                              |
|-------------------------|----------------------------------------------------------|
| [`ptyx`](packages/ptyx) | High-throughput local pseudo-terminal sessions for Dart. |

Each package has its own API, platform support, version, and release cycle.
